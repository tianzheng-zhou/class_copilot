# Class Copilot — 独立重构

这是 `refactor/next` 分支，从功能与需求文档开始完整重构。代码、接口和数据模型重新设计，旧版保留在 `main`。

## 当前状态

- 已完成旧版功能审计，以及新版产品需求、技术设计和接口契约；业务代码尚未开始实现。
- 已确认：Ubuntu 优先、统一课堂工作台、课后继续聊天/回答/总结、三种自动处理模式、正式录音导入。
- 语音识别使用用户指定的 `qwen3.8-omni-flash`，按音频分段持续转写。
- 新版使用独立空数据库，旧记录留在旧版；不迁移或修改旧数据。
- 新分支采用独立提交历史；新版文档区分用户确认项、设计默认值和待验证能力。

## 推进方式

1. 后续功能调整直接修改新版产品需求，对应更新接口及验收条件。
2. 按技术设计中的 M1～M4 实施：基础与工作台 → 音频/转写 → 问答/聊天/总结 → 完整稳定性验收。
3. 每阶段记录实际通过的测试；模型、设备和长时间运行单独验收。
4. 代码发布和主线切换另行安排。当前文档不代表可运行软件。

独立历史与 `main` 没有共同祖先，后续不能按普通功能分支直接合并；正式发布时另行选择主线切换或显式合并无关历史的方式。
