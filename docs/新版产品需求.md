## 2. 产品目标与范围

Class Copilot 是本机单用户课堂助手：课中记录音频并持续获得转写和问答，课后在同一课堂中复习、追问、总结和导出。应用、数据库和录音保存在本机；识别和生成使用云端模型，首次配置说明相关音频及文本会发送到所选服务。

首版采用本机服务加浏览器，支持 Ubuntu 上的麦克风、指定系统声音来源和录音文件。保留中文、英文及中英混合识别；界面语言与生成语言分开设置。

首版不包含账号、多人协作、跨设备同步、桌面壳、移动端录音、离线模型、教师/说话人识别、麦克风与系统音频混音、资料知识库、人工编辑转写、批量导入、PDF 导出或旧数据库迁移。无需为这些能力预建微服务或插件系统。

## 3. 核心对象与使用流程

| 对象 | 用户含义 | 规则 |
| --- | --- | --- |
| 课程 | 一组课堂记录，例如“线性代数” | 可创建、改名；仅空课程可删除 |
| 课堂 | 一节课的长期记录 | 不依赖录音存活；可多次打开和继续使用 |
| 音频来源 | 一次录音或一个导入文件 | 属于一节课；保存来源、顺序、时长和处理状态 |
| 转写片段 | 来源音频中的一段文本 | 可追溯到来源和音频时间范围 |
| 课堂问题 | 系统检测或用户指定的问题 | 保留来源片段；与主动聊天分开 |
| 答案版本 | 对课堂问题的一次回答 | 保留简要/详细、模型、生成状态和历史版本 |
| 聊天 | 用户在该课堂中的连续追问 | 停止录音后仍可继续；每条回复有独立状态 |
| 总结版本 | 基于当时课堂内容整理的复习材料 | 有内容覆盖范围；后续新增内容不改写旧版本 |
| 任务 | 正在转写、检测或生成的工作 | 可查询状态；适用时可取消或重试 |

典型流程：创建课程 → 创建课堂 → 选择音源录音或导入文件 → 查看转写和问答 → 停止录音/处理完成 → 聊天、补充答案、生成总结 → 复习与导出。

允许在已有课堂追加一次录音或导入文件；每次形成独立音频来源，按加入顺序排列。首版没有“暂停”按钮：停止后再次录音会创建新来源，间隔不会伪装成连续录音。

## 4. 页面与交互

| 页面 | 内容与主要操作 |
| --- | --- |
| 课堂列表 `/` | 按课程筛选、名称搜索、日期范围、分页；创建课堂；进入课堂；改名和删除 |
| 工作台 `/lessons/:id` | 统一展示转写、问答、聊天；录音控制；音频列表/播放器；总结；导出 |
| 设置 `/settings` | 服务连接与 Key、音源和测试、模型与语言、默认处理方式、课程管理、高级设置 |

工作台的信息位置：

```text
课程 / 课堂名称       录音状态 · 转写进度       音源 / 开始或停止 / 更多
处理模式：自动问答 / 仅检测 / 仅转写          音频来源 / 总结 / 导出
┌────────────────┬────────────────┬────────────────┐
│ 转写            │ 课堂问答        │ 聊天            │
│ 按来源和时间排列 │ 问题与来源      │ 本课堂对话      │
│ 当前识别进度    │ 答案及版本      │ 模型/思考选项   │
│ 选片段提问      │ 回答/重试/取消  │ 输入框          │
└────────────────┴────────────────┴────────────────┘
```

- 桌面宽屏同时展示三栏，可调宽度；较窄窗口使用可切换面板。切面板不暂停录音或任务，输入草稿不丢失。
- 总结在工作台内以侧栏或独立面板打开；不会替换或清空聊天。
- 离开工作台时，全局仍显示正在记录的课堂及停止入口。关闭标签页不停止后端录音；开始前明确这一行为。
- 停止按钮只停止采集；转写收尾和答案生成有各自状态，不用一个“处理中”混淆全部工作。
- 有明确的空状态：未配置、没有课程、空课堂、尚未识别到问题、没有录音、没有总结、服务断开。

## 5. 功能需求

### R-01 首次启动、数据隔离与课程

1. 新版使用独立数据目录 `data/next/`，包括新数据库、录音、上传文件、日志和凭据；不扫描、转换或删除旧库与旧录音。
2. 首次启动为空，不带示例课堂。无需 Key 也能管理课程、查看已有记录和导出；调用模型时才要求配置完整。
3. 新版 Key 和模型连接重新填写，不自动读取旧版配置。目录、依赖或权限有问题时显示可操作的错误。
4. 课程名去首尾空白，长度 1～100 字符，按规范化后的名称检查重名；有课堂的课程不可直接删除。
5. 课堂属于一门课程；名称可自定义，清空后显示“课程名 · 创建时间”。允许只创建课堂而暂不录音。

### R-02 录音、音源与计时

1. 选择麦克风或系统声音，并明确显示实际设备。设备消失时提示重新选择，不悄悄切换到另一设备。
2. 音量测试持续 5 秒，测量所选音源，不创建课堂内容。录音中电平来自同一采集流，不另开麦克风。
3. 同一后端同时只运行一项音频处理：一路实时录音及其转写收尾，或一个导入分析任务。问答、聊天和总结可独立运行。
4. 开始前检查音源、磁盘、模型配置和当前占用；重复点击或多个标签同时开始，不创建重复录音。
5. 默认无自动停止，可设置 15/30/45/60/90 分钟或自定义 1～240 分钟。时长从本次录音开始计算；改成已过去的时长会立即开始停止流程，页面提前提示。
6. 到期、手动停止和应用正常退出使用同一套收尾逻辑。停止后立即停止新增采集；已经录下的音频继续保存和识别。
7. 首版每个来源最长 4 小时；无限时表示未主动设置倒计时，仍受此单次上限约束。到达上限自动收尾，并允许稍后向同一课堂追加新来源。
8. 浏览器刷新、切页和模型回答缓慢都不能阻塞停止录音。

### R-03 持续转写与音频保存

指定模型按短音频分段处理，界面用“持续转写”表达体验，不承诺逐字即时识别。官方将该模型列为 HTTP 音频输入、文本输出模型；具体接入见技术设计。[模型说明](https://help.aliyun.com/en/model-studio/qwen3-8-omni-flash)

1. 音频先保存，再进入转写；文字生成缓慢不影响采集。界面显示已录时长、已识别进度和积压。
2. 分段初值为遇到合适静音提交、最长 12 秒；这些是本地策略，不是云端限制。实际等待包含分段时长、排队和模型耗时，必须真实量测。
3. 转写保留原语种，混合语言不强制翻译；只记录听到的内容，不用聊天回答或摘要替代原话。没有听清时保留不确定标记。
4. 流式返回尚未完成的文字显示为草稿；只有成功完成并持久化的文本才触发自动检测。失败的草稿不当作确认内容。
5. 每段显示对应音源及大致时间范围，可定位播放；首版只保证音频块范围，不承诺逐字时间戳。
6. 静音、边界处的重复、真实的重复讲解要区分处理；去重只针对重复任务或重叠范围，不全局删除相同句子。
7. 停止时提交最后不足完整长度的一段。部分识别失败时仍可播放和下载录音，并明确显示未识别区间及重试入口。
8. MP3 是标准播放/下载格式；录制和转换中保留可恢复的音频块。导入的原文件也保存，可单独下载。

### R-04 正式导入录音

1. 用户在课堂中选择本机文件上传；不输入后端绝对路径。首版支持 MP3、WAV、M4A、FLAC、OGG，单文件不超过 500 MiB、时长不超过 4 小时。
2. 扩展名仅用于筛选，实际解码和时长检查通过后才可分析；损坏、无音轨、超限或空间不足有明确错误。
3. 提供上传进度和分析进度，二者分开。上传完后选择/确认处理模式及是否自动生成总结，默认自动问答并生成总结。
4. 仅检测模式只新增问题；仅转写模式不自动检测和回答；总结是独立选项，在三种模式下都可选择。
5. 导入按处理能力推进，无需按原音频的播放速度等待；与实时录音使用相同的转写、问题和答案存储。
6. 取消分析保留原文件和已经完成的内容；再次处理只补未完成音频块，不重复添加问题。上传未完成时取消则清除未完成临时文件。
7. 上传成功但尚未开始分析的文件有可见状态。相同文件再次上传时提示已存在的来源，避免误重复。
8. 自动总结等待该来源的转写和自动问答进入终态。存在失败区间或答案失败时，总结说明覆盖不完整；全部无有效转写时不生成虚假总结。

### R-05 自动问题检测与三种模式

| 模式 | 新最终转写 | 自动检测问题 | 自动生成答案 |
| --- | --- | --- | --- |
| 自动问答 `auto_answer` | 保存 | 是 | 是 |
| 仅检测 `detect_only` | 保存 | 是 | 否，保留“待回答”问题 |
| 仅转写 `transcribe_only` | 保存 | 否 | 否 |

- 默认值用于新课堂；课堂自己的模式独立保存。切换后对新完成转写生效，不删除旧内容、不自动回扫全文。
- 每个检测任务记录触发时的模式版本。切换模式时取消旧版本尚未运行的自动任务；已运行的检测可保存问题，但切到非自动回答模式后不能再触发自动答案。已运行的答案保留，可单独取消。
- 自动检测只处理已保存的最终文本。检测置信度、冷却和相似问题过滤按课堂隔离；首版高级设置可调，但普通用户不需要理解算法参数。
- 所有模式都保留手动入口：“从选中内容找问题”“回答这段内容”。没有有效转写或没有选择时说明原因，不发送空任务。
- 手动找问题绕过自动冷却，但保留重复提示；直接回答按选中内容生成问题卡及参考答案，不必先通过问题检测。

### R-06 答案与版本

1. 支持简要、详细两档及中文、英文、中英双语输出；一次只生成所选档。
2. 问题卡显示待回答、排队、生成中、完成、失败或已取消。失败/取消保留已经持久化的部分文字并明确标记。
3. 可重新生成、切换档位或模型；新答案形成新版本，旧答案保留。默认显示最近成功版本，进行中的版本另显示进度。
4. 切换全局设置不隐藏已有答案。导出包含全部版本和各自状态。
5. 录音结束后仍可检测已有转写、回答待答问题或重新生成答案。
6. 生成内容标明是 AI 参考答案；关联课堂片段，无法从上下文确定的内容说明不确定。首版不默认联网搜索。

### R-07 课堂聊天

1. 每节课一条连续对话；可在录音中、停止后或历史课堂中发消息。空课堂可一般提问，并提示当前没有课堂上下文。
2. 发送后立即保存用户消息和待回复记录；服务失败不会让用户消息消失。每节课同时只生成一条聊天回复，第二次发送返回忙碌提示并保留草稿。
3. 可选择快速/质量和思考开关；模型能力不支持时禁用并说明，不传无效参数。选项记录到每次任务。
4. 支持停止生成、失败重试；重试不复制用户消息，回复保留各次尝试。后续上下文默认使用最近成功的回复版本。
5. 上下文包括相关课堂内容与近期对话，有统一长度预算；需要裁剪时提示覆盖范围，不重复发送完整历史。
6. Enter 发送、Shift+Enter 换行；生成期间仍可停止录音。另一课堂的回复不能串入当前页面。

### R-08 课堂总结

1. 工作台提供“生成总结”；导入分析支持完成后自动生成；实时录音停止后提供按钮，不自动额外调用。
2. 总结默认包含知识点、概念解释、课堂问题与结论、待确认内容和复习建议。没有材料的栏目可为空，不凭空补齐。
3. 默认基于最终转写、课堂问题和成功答案；聊天不默认混入讲课内容，可显式选择纳入。
4. 记录生成时的内容版本、覆盖片段和失败区间。后续追加音频或答案时显示“有新内容，可更新总结”。
5. 重新生成保留历史版本；支持取消和失败重试，旧成功版本始终可读。
6. 长课堂分段提炼后再合并；进度可见。没有有效转写时不允许生成课堂总结。

### R-09 查找、播放、导出与删除

1. 列表支持课程、课堂名称/课程名、日期范围、分页；按创建时间倒序。本机时区决定显示和日期分组，存储使用 UTC。
2. 可以改名、清空自定义名称；首版不做全文搜索、转写编辑或移动课堂到另一课程。
3. 内嵌音频播放器支持播放、暂停、进度跳转和倍速；转写定位到相应来源的大致时间。
4. Markdown 导出包含课堂信息、全部最终转写、问题、所有答案/聊天回复/总结版本、失败或未完成标记。连续用户消息和未回复消息都保留。
5. 下载单个来源的标准音频；导入来源还可下载原件。音频缺失时说明缺失，不返回内部路径或服务器错误页。
6. 删除课堂需要确认关联文字、版本和音频范围；有录音、分析或生成任务时拒绝删除并提示先停止/取消。
7. 删除文件失败时显示清理未完成并可重试；不把部分清理报告为完全成功。课程统计与课堂可见状态保持一致。

### R-10 设置、模型与凭据

1. 首版供应商为阿里云百炼；用户配置工作空间对应的服务地址、区域和 Key，不根据电脑时区推断区域。
2. 语音模型固定默认 `qwen3.8-omni-flash`。检测、回答、聊天、总结分别设置模型，不再将模型字符串散落在业务代码中。
3. 文本模型的首版设计默认：检测/自动回答/快速聊天/总结用 `qwen3.8-flash`；质量聊天可选 `qwen3.8-max`。这是技术选型，不是用户指定；实际区域可用性在接入验收中验证。[官方文本模型介绍](https://help.aliyun.com/en/model-studio/text-generation-model/)
4. Key 可保存、替换、清除；公开接口只返回“已设置”和脱敏标识。提供显式连接测试，说明会发起测试调用，不在保存时偷偷调用模型。
5. 设置使用明确的“保存/取消”；一次提交原子生效；离页有未保存提示。多个标签修改同一版本时提示冲突。
6. 音源、采样和识别设置在下一音频来源生效；生成设置在下一任务生效；课堂模式单独立即保存，按 R-05 的边界执行。
7. 界面语言为中文/英文；主题为浅色/深色/跟随系统。保存在浏览器，不影响课堂内容或模型语言。
8. 高级参数只展示当前适配器实际生效的参数。删除旧版无效的云端 VAD/连接轮换选项，不保留装饰性开关。

### R-11 故障、刷新和多标签

1. 刷新后恢复课堂已保存内容、任务和录音状态；重连补齐新增内容，不只恢复一个“录音中”标志。
2. 多标签查看同一课堂得到相同结果；服务器串行处理冲突操作。所有任务和事件明确归属课堂、来源或消息。
3. 断网时不积攒待补发的开始、停止和聊天命令。请求结果不确定时先查询状态，重复请求使用同一幂等标识。
4. 云端不可用时保留本地录音及已完成文字，展示待识别内容。短暂故障有限重试，持续失败不无限消耗请求。
5. 正常退出进行有限时间收尾；意外退出后标记中断、恢复可用音频和任务状态，不自动打开麦克风或自动重跑付费生成。
6. 录音写盘失败立即停止采集；模型故障与磁盘故障分别提示。任何可能丢失的音频范围都应显式标记。
7. 日志可按课堂/任务定位，不记录 Key、完整请求正文或整段课堂内容。
