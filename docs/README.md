## 如何用这些文档推进重构

1. 修改 [新版产品需求](新版产品需求.md) 的 R-xx 与 V-xx；用户决定记录在 C-xx。
2. 技术实现变化同步更新技术设计和接口契约；行为变更必须有验收条件。
3. 旧编号 F-01～F-37 已逐项对应新版，新增能力使用 NEW-001～NEW-007。
4. 按 M1～M4 实施与验证，保留旧版文档用于行为比对，不把旧缺陷复制为要求。
